# NEXUS BRILL CITY — официальный сайт RAGE:MP

Действующий сайт: https://77.42.93.209/nexus-city/

Личный кабинет: https://77.42.93.209/nexus-city/portal.html

Административный интерфейс: https://77.42.93.209/nexus-city/admin.html

## Структура

- `index.html`, `new.css`, `new.js` — публичная главная.
- `portal.html`, `dashboard.css`, `dashboard.js` — интерфейс веб-кабинета.
- `admin.html`, `admin.js` — административная панель сайта.
- `backend/app.py` — локальный Python API и SQLite для веб-пользователей, заявок, новостей и правил.
- `backend/snapshot.py` — ограниченный экспорт публичного рейтинга персонажей из игровой MySQL-базы.

## Текущее состояние

Публичные страницы, административная форма, новости, правила, заявки и рейтинг доступны. API административных действий проверяет роль пользователя. Статус игрового процесса проверяется локально. Рейтинг берётся из игровой базы и обновляется примерно раз в минуту.

### Ограничения

Веб-аккаунт не связан с игровым аккаунтом RAGE:MP. Счётчик реально подключённых игроков не интегрирован. Решения по заявкам на сайте не назначают игровые роли автоматически. Краткие правила требуют утверждения администрации. Полный цикл регистрации и авторизованных действий в браузере нужно дополнительно проверить перед объявлением функционала полностью принятым.

## Развёртывание

Production-копия находится на VPS `77.42.93.209`. Nginx обслуживает путь `/nexus-city/` в существующем HTTPS виртуальном хосте. Python API слушает только `127.0.0.1:18852` через systemd `nexus-city-portal.service`. Статистика обновляется `nexus-city-stats.timer`.

**Никогда не размещать SQLite с веб-аккаунтами, резервные копии базы, cookies, ключи, реальные пароли или `.env` в публичном репозитории.** При развёртывании необходимо сохранить изоляцию API и ограничить чтение игровых данных. Не заменять существующую конфигурацию Nginx или игровой сервер без резервной копии и проверки.
